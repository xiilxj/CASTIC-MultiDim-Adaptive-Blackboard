## 📖 项目简介 (Project Overview)

本项目源于中学生在日常教室学习生活中的真实痛点观察：传统推拉黑板长期存在**“窗侧漫反射眩光致盲区（反光看不清字）”**、**“粉笔灰堆积卡死滑槽导轨”**以及**“多媒体大屏显示与大面积物理板书不可兼得”**三大工程沉疴。

针对上述问题，本项目秉持**“身边真实痛点驱动、多轮原型科学探究”**的工程学原则，历经三代代际拓扑演进，提出了基于**“对角线双铰链正交解耦（Diagonal Topology）”**的多维叠合翻转全覆盖与三维自洁侧滑智能黑板系统。

```
【传统推拉黑板】             【第一代翻转黑板】             【第二代三维联动黑板】            【第三代多维叠合黑板 (Z系列)】
4000mm 固定双轨推拉  ──►   阻尼偏心单铰链 178°   ──►   三维避光 (偏航+俯仰+侧滑)   ──►   对角线双铰链两折叠并成
卡灰卡阻、大屏板书冲突       视场扩展、Canopy遮光         倒V排灰孔、偏光膜AI闭环        三大工况大一统 (4000~6000mm)
```

## 🌟 核心工程创新点 (Key Innovations)

### 1. 对角线双铰链正交解耦机构 (Diagonal Orthogonal Decoupling)
- **外层内侧折叠铰链 ($X = \pm 1000\text{mm}$)**：负责外层 12mm 超薄副板向黑板中心 180° 铺开，与对侧副板合拢锁死，形成 4000mm 市面主流全覆盖封屏；
- **内层外侧翻转铰链 ($X = \pm 2000\text{mm} \to \pm 3000\text{mm}$)**：负责两层贴合后的黑板模组整体实现 $-15^\circ \sim +15^\circ$ 俯仰与水平偏航避光；
- **俯视对角线分布**：两组旋转副在空间截面上呈对角线分离，从根本上消除了双层板叠合时的厚度几何干涉与运动学死点。

### 2. 三大核心使用工况大一统
- **工况一【初始闭合·市面主流全覆盖形态】**：总跨度 4000mm，双侧内板合拢锁死，100% 遮蔽保护 86 寸液晶大屏，提供纯板书沉浸教学；
- **工况二【常态多媒体·大屏露显双层叠合形态】**：总跨度 4000mm，副板向后 180° 回折贴合于主板前方（叠合总厚度仅 26mm），露显 86 寸交互大屏；
- **工况三【大视野与避光·平移侧滑极限展开形态】**：总跨度延展至 6000mm，双层板沿高刚性 $\Phi 28\times 2.5\text{mm}$ 双梁伸缩套杆外滑 1000mm，配合端部垂直拉杆形成闭环门式刚架，大屏与左右板书完整呈现，并支持多维避光旋转。

### 3. 双横梁自洁防卡阻滑槽系统
- 倒 V 型 EPDM 弹性密封导流罩，阻隔 92% 以上直落粉笔尘；
- 滑槽底部沿轴向每隔 200mm 开设 $\Phi 12\text{mm}$ 垂直落灰孔，消除活塞气阻并自然落尘；
- 滑块端面高密度尼龙毛刷条往复刮扫，实现免维护自洁。

## 🛠️ 复现与构建指南 (Build & Reproduction)

### 1. 编译正式交付报告 (PDF)
本项目报告采用现代学术排版系统 [Typst](https://typst.app/) 编写：
```bash
cd "04-汇报与交付报告"
# 使用内嵌中文字体编译高精度 PDF
typst compile 面向VLM赋能教室光环境的多维教学黑板机构学设计与代际拓扑演进_第一阶段技术测验报告_v1.0.typ \
  --font-path fonts/ --root ..
```

### 2. 自动化生成 AutoCAD 2026 DWG 图纸
在已安装 AutoCAD 2026 的 Windows 环境下，通过 Python COM 接口直接驱动绘图：
```bash
cd "03-脚本与自动化源码"
python draw_gen3_blackboard_system_v1_2.py
```
