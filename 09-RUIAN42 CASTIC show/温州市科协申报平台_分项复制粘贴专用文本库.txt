【表单项 2：项目摘要（Abstract）】（建议字数 600 - 1000 字）
--------------------------------------------------------------------------------
中小学普通教室普遍存在临窗席位“眩光死角”与“白灼刺眼”难题。传统推拉黑板局限于墙面二维平移，法向偏航角恒为零，无法在三维空间切除直射日光反射通道；而传统“拉窗帘开全灯”的被动妥协方式不仅斩断自然采光，更导致单间教室日照明耗电达 7.13 kWh，严重损害学生视力健康。

针对上述工程痛点，本项目历时 14 个月四次工程代际演进与 83 次 Git 提交存证，研发出一套融合空间机构正交解耦与端侧视觉语言大模型（VLM）闭式控制的智能多维消眩教学黑板系统（GH-VI-2026）。核心创新与成果包括：
1. 机构学突破：发明对角线错位双铰链空间正交解耦机构（VI 系列），彻底将垂直自重剪切重载与水平偏航旋转运动正交解耦，消除自重下垂卡死顽疾与底部凹槽粉笔灰泥泥阻，整机贴墙极限厚度压缩至 26 mm，支持 4m-8m 跨度展开与 0°-18° 空间微倾自适应避光；
2. 数理机理大一统：建立统摄教室空间流形、双相 Cook-Torrance/Oren-Nayar 微表面磨损 BRDF 物理卷积、4 组 2-DOF 空间定向灯场及眼内前向散射（CIE 117-1995/Vos-van den Berg）的物理光学与人因感知大一统偏微分-积分主方程；严格数学推导证明了直射光切断工况下的经典常解渐近退化收敛性，并量纲对齐验证其绝对自洽；
3. 端侧确定性闭式闭环：构建“端侧轻量化 VLM 定性识别反光斑 + 逆透视投影 (IPM) 与 2-DOF 云台空间逆运动学代数确定性闭式解 + 嵌入式硬件伺服驱动”的工业级双层架构，杜绝大模型计算延迟与浮点数幻觉，控制全链路时延 < 35 ms；
4. 全真物理仿真与实机验证：在原生 MATLAB R2025b 离散数值仿真（81×37=2997 节点）与样机运行中，系统将靠窗最险席位失能光幕眩光从 1285.6 cd/m² 断崖式压制至 23.8 cd/m²（眩光抑制 54.0 倍），视感知 Weber 动态对比度从 0.169 跃升至 7.410（清晰度提升 43.9 倍），全日照明节电率达 67.00%。

【表单项 3：选题目的与研究背景】
--------------------------------------------------------------------------------
青少年近视防控已成为国家健康战略。《GB 7793-2010 中小学校教室采光和照明卫生标准》明确要求普通教室黑板维持平均照度 ≥ 500 lx 且严格限制反射眩光。然而我国南方沿海地区（如浙南地带）日照强烈，传统黑板经千百次粉笔摩擦后釉面局部磨损抛光，在自然光入射下极易产生高光刺眼反射，造成靠窗座位同学视物困难。

现有解决方案存在显著缺陷：
1. “拉窗帘开日光灯”形成昏暗压抑的“暗室教学”，单间教室日耗电高达 7.13 kWh，能耗巨大；
2. 传统推拉黑板仅能进行墙面二维刚性平移，法向角度恒为零，机械自由度锁死；
3. 滑轨下凹槽长期沉积粉笔灰，形成活塞泥阻，容易导致滑轮脱轨与卡死；
4. 电致变色玻璃/调光膜成本高昂（整板数万元），且表面硬度不足，无法耐受粉笔反复划擦。
因此，自主研发一套超薄空间占用、大悬臂抗下垂、防粉尘卡死且具备端侧智能消眩能力的教学黑板，具有迫切的现实需求与广阔的推广应用前景。

【表单项 4：研究过程与技术路线（工程研发历程）】
--------------------------------------------------------------------------------
本项目严格遵循规范的现代工程研发全生命周期（需求定义 -> 运动学分析 -> 机构仿真 -> 试制验证 -> 算法闭环），历经 14 个月四次工程代际拓扑演进与 83 次 Git 提交存证：
1. 第一代（S 系列，2025.09-2025.12）：单立柱偏心单铰链 178° 翻折机构。试验发现外悬臂长达 2.0m，偏心重力导致巨大倾覆弯矩，根部微形变致使门页下垂卡死。迭代决策：淘汰单悬臂方案，探索多点载荷分流；
2. 第二代（Z 系列，2026.01-2026.04）：上下双滑轨推拉复合折叠连杆机构。测试暴露下轨道槽大量沉降粉笔灰形成硬质灰泥，滑轮产生活塞卡阻，且折叠重合发生空间干涉。迭代决策：彻底摒弃地面滑槽，探索非接触式空间解耦铰链；
3. 第三代（VI 系列，2026.05-2026.08）：发明对角线错位双铰链空间正交解耦机构。将垂直刚性重力承载与水平偏航旋转完全解耦，对角线错位消除运动死点，整机折叠厚度仅 26mm，支持 4m-8m 展开。确立为核心机械拓扑构型；
4. 第四代（VLMC 系列，2026.09-2026.11）：端侧轻量化 VLM 具身感知与 2-DOF 空间定向灯场闭环。建立物理光学大一统主方程，推导出毫秒级代数闭式控制律，完成实机全闭环工程落地。

【表单项 5：项目主要创新点】（建议分条陈述，条理分明）
--------------------------------------------------------------------------------
1. 机构拓扑创新：发明对角线错位空间正交解耦双铰链机构。
首次将黑板门页垂直自重剪切重载与水平偏航旋转运动彻底解耦，消除门页下垂变形与传统滑道粉笔灰积泥卡死顽疾。折叠厚度极限压缩至 26 mm，兼具结构高刚度裕度（提升 3.8 倍）与 4.0m-8.0m 空间灵活偏转避光。

2. 数理机理创新：构建微表面 BRDF 磨损演化与空间辐射输运大一统偏微积分主方程。
突破传统照明割裂离散计算局限，建立首个统摄教室三维空间流形、双相 Cook-Torrance/Oren-Nayar 涂层抛光演化与人眼生理前向散射（CIE 117-1995/Vos-van den Berg）的大一统数理模型，并严格推导证明了直射光切断工况下的经典解析常解收敛性（MATLAB 仿真误差仅 1.7%）。

3. 工业控制创新：创立轻量化 VLM 与底层代数确定性闭式解双层工业控制架构。
采用“端侧视觉大模型定性识别光斑 + 逆透视投影 (IPM) 与 2-DOF 空间逆运动学代数闭式解 + 嵌入式硬件伺服驱动”的双层架构，彻底解决大模型端侧推理延迟与浮点数计算幻觉，实现全链路响应时间 < 35 ms 的高可靠硬实时控制。

4. 绿色低碳创新：兼顾护眼健康与建筑节能。
变传统“拉遮光帘关自然光开全灯”的被动妥协为“定向微倾避光+高精度局部增亮”的主动适配，在彻底消除靠窗白灼反光的同时，全日照明耗电从 7.13 kWh 降至 2.35 kWh，综合节电率达到 67.00%。

【表单项 6：客观实测与模拟仿真数据对比】
--------------------------------------------------------------------------------
在原生 MATLAB R2025b 离散数值仿真（81×37=2997 物理节点，0 NaN，0 Inf）与真实样机运行中获得客观验证数据：
1. 最险席位失能光幕亮度：由 1285.6 cd/m² 降至 23.8 cd/m²，眩光抑制 54.0 倍；
2. 靠窗高危席位 Weber 动态对比度：由 0.169（严重失能）提升至 7.410（清晰视物），对比度跃升 43.9 倍；
3. 全教室 48 席位照度均匀度：由 0.58 提升至 0.86，完全符合国家健康照明规范；
4. 全天 8 小时照明能耗：由 7.13 kWh 降至 2.35 kWh，综合节电率 67.00%；
5. 闭环控制全链路时延：< 35 ms，运行平稳无震颤。
数据客观性说明：最险位反差拉平线实测约 7.5（略低于清洁新黑板极限常解 11.85），因为模型严格代入了真实磨损因子 w = 0.6 与粉笔灰沉积，完全立足真实工程工况，绝无数据虚标。
