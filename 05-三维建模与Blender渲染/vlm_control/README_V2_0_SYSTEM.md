## 一、 系统核心技术亮点

1. **硬件双通道即插即用（机内 vs 外接 USB）**：
   - 自动扫描系统物理视频设备，开机探测；
   - 快捷键 `[C]` 零卡顿无缝循环热切：
     - `Device 0`：笔记本内置高清镜头；
     - `Device 1+`：外接 USB 高清广角相机 / 运动相机；
     - `SIM`：离线数字孪生教室光环境仿真流（断网/无外接设备时 100% 稳定运行保障）。

2. **科学调控逻辑重大升级（以“调控光环境”取代“频繁晃动黑板”）**：
   - **评委质疑致命点化解**：黑板如果在上课时频繁转动 18 度，会打断板书并引起眩晕。
   - **科学新方案**：黑板保持 **4.5° 黄金防眩微倾基准锁定**；VLM 核心调控对象为**教室光环境主动重塑**：
     - **智能电动百叶窗**：动态下发遮阳比例（0%~100%）与叶片倾角，从源头阻断侧窗太阳直射强光；
     - **黑板自适应洗墙灯**：动态调光（100W~240W）与色温调节（3000K~5500K），弥补遮光后的板面明暗阴影，恢复 1:12 优质对比度；
     - **阵列护眼筒灯**：维持教室整体均匀度，实现综合节能 38%。

3. **业界顶尖端侧小型 VLM 架构**：
   - 摒弃早期较弱的初代小模型，引入当今端侧霸榜模型：
     - **MiniCPM-V 2.6 (默认)**：端侧性能巅峰，单图综合超越 GPT-4V；
     - **InternVL 2.5**：国家队科学级多模态，物理因果链推导极强；
     - **Qwen2.5-VL**：阿里最新动态分辨率版。
   - 快捷键 `[M]` 自由循环切换。

4. **实时多模态对话框与工具调用回显**：
   - 支持键盘打字输入 Prompt，光标实时闪烁；
   - 预设快捷宏 `[1]`、`[2]`、`[3]` 一键触发典型答辩场景；
   - VLM 打字机流式回显图像多模态推理链；
   - 底部高亮滚动打印结构化 Agent Tool Calls（IPC 同步至 Blender 3D 数字孪生）。

## 二、 现场操作快捷键清单

| 快捷键 | 功能描述 | 现场演示用途 |
| :---: | :--- | :--- |
| **`[C]` / `[c]`** | **切换摄像头输入源** | 在笔记本机内摄像头、外接 USB 相机、数字孪生仿真流之间切换 |
| **`[M]` / `[m]`** | **切换 VLM 大模型** | 循环切换 MiniCPM-V 2.6 / InternVL 2.5 / Qwen2.5-VL |
| **`[1]`** | **场景 1 宏：靠窗学生眯眼诊断** | 模拟学生强光眯眼，VLM 自动下发百叶窗降下 70% + 洗墙灯补偿 220W |
| **`[2]`** | **场景 2 宏：黑板高光白斑消除** | 模拟黑板出现反光镜面斑，洗墙灯与百叶窗协同重塑 |
| **`[3]`** | **场景 3 宏：全室光照健康自平衡** | 演示阴天/黄昏状态下光照自平衡，微倾锁定与绿色节能运转 |
| **`[ESC]` / `[Q]`**| **安全退出系统** | 关闭窗口并释放摄像头资源 |
