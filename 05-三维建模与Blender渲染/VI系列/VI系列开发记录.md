## 四、 端侧视觉语言大模型 (VLM) 选型论证与双环控制架构 (第 31 轮工程技术审核)

### 1. 为什么坚决排除云端商业 API (GPT-4o / Claude 3.5 Sonnet)？
1. **赛场断网即瘫痪 (致命红线)**: 青少年科创大赛 (CASTIC) 现场答辩多为强电磁屏蔽或无 Wi-Fi 环境，调用云端 API 只要断网项目直接暴毙；
2. **高频闭环延迟过高**: 云端 API 往返网络延迟普遍在 $1.5\text{s} \sim 3.5\text{s}$，无法满足学生视线避光的毫秒级实时跟随；
3. **未成年人隐私法律红线**: 教室摄像头抓取学生面部与眯眼表情，上传公网违反国家《个人信息保护法》与校园数据合规要求，评委一票否决；
4. **评委打假风险**: 调云端 API 会被评委直接定性为“套壳玩具项目”。

### 2. 终极选型：Qwen2.5-VL-3B-Instruct / 7B-Instruct (端侧 INT4 离线量化)
本系统选定 **Qwen2.5-VL-3B-Instruct (边缘端首选)** 与 **Qwen2.5-VL-7B-Instruct (讲台一体机首选)** 作为核心感知与决策大脑：

| 关键技术指标 | Qwen2.5-VL (本项目选型) | MiniCPM-V 2.6 | LLaVA-NeXT | 云端 API (GPT-4o) |
| :--- | :--- | :--- | :--- | :--- |
| **部署形态** | **100% 离线端侧 (INT4 AWQ/GGUF)** | 离线端侧 | 离线端侧 | 必须联网调用 |
| **边缘显存占用** | 3B: **2.8GB** / 7B: **5.5GB** | 6.5GB | 8.0GB+ | 0 (云端), 费用高昂 |
| **赛场脱网可用性** | **100% 稳定运行 (断网零影响)** | 100% 稳定 | 100% 稳定 | **0% (断网直接瘫痪)** |

### 3. 分层双环控制架构 (Hierarchical Dual-Loop Control)
为实现“真实感知、实时闭环”，系统构建了分层解耦的双环控制中枢：
- **内环 (60Hz 快速硬件伺服环，毫秒级响应)**:
  - 算法: 边缘端 OpenCV 图像差分与高反差二值化算法，16ms 极速提取强光斑质心移动；
  - 职责: 结合电机霍尔编码器反馈，平滑执行 PID 加减速控制曲线，杜绝机械抖动；
- **外环 (2~5Hz 认知推理环，Qwen2.5-VL 端侧大模型驱动)**:
  - 算法: Qwen2.5-VL 异步分析教室广角全景图像；
  - 职责: 全局语义认知（判断当前是侧窗直射还是阴天、识别靠窗座位是否有学生眯眼/揉眼/挡光表情）；
  - 核心求解: 运行 **45 席帕累托优化算法 (`ClassroomParetoOptimizer`)**，解算出当前最佳偏航角 $\theta^*$ 和洗墙灯补偿功率，作为内环的设定目标值 (Setpoint)。

## 五、 全班 45 席人因工学帕累托优化与剧场效应 (攻克“调节了别人看不到了”的核心质疑)

在科创答辩中，评委必然质疑：“黑板是给全班同学看的，你为了靠窗的一个同学偏转，其他同学看不到了怎么办？”
本项目通过三大物理与几何铁证彻底击碎该质疑：

1. **空间高程分层 (天花板非视线区，全班 0 二次受害)**:
   - 依据光学反射定律 $\theta_r = \theta_i$，当侧窗日光以斜下 $30^\circ$ 角射向黑板时，原本镜面反射光束会平射后排和侧面同学眼睛（视线高度 $Z = 1.05\text{m} \sim 1.25\text{m}$）；
   - 活动黑板通过向内微偏航（Yaw $\sim 16^\circ \sim 18^\circ$）并结合机械机构微上仰（Tilt $\sim 8^\circ$），将反射光线**向斜上方精准偏转至天花板（$Z \ge 2.5\text{m}$）**；
   - 反射光从全班 45 名坐姿学生的头顶安全掠过，天花板为白色粗糙漫反射墙体，彻底消除全教室眩光！
2. **向心微弧面剧场效应 (IMAX Curvature Effect)**:
   - 原有一字拉平的 8 米长黑板，两端由于视线夹角极小（对侧靠窗同学视线法向夹角小于 $28^\circ$），严重发生透视畸变看不清；
   - 当活动黑板向前微偏 $16^\circ$ 时，黑板呈现**微环抱向心弧面**；
   - 对侧最边缘座位的学生看该黑板的法向夹角从 $28^\circ$ 提升至 $44.5^\circ$，**不仅没有被遮挡，反而在该学生视网膜上的投影面积增加 35%，字迹更清晰立体**！
