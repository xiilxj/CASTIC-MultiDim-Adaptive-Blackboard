1. 📂 专利申请摘要

本实用新型公开了一种基于三维空间联动避光与轨道自洁的防眩光智能教学黑板系统。该黑板包括主体框架、控制模块、设于主体框架两侧的左右承重转轴铰链、横向可延展伸缩框架组件、以及滑动挂载于所述伸缩框架组件上的黑板主体；所述横向可延展伸缩框架组件平行挂载于所述承重转轴铰链上，且包含双横梁固定外框与嵌套滑动延伸内轨；所述黑板主体与延伸内轨构造成偏航旋转、纵向俯仰与横向侧滑的三维复合运动副。该光环境系统包括设于所述主体框架上方的多模态图像传感器、设于教室内各个物理座位上的分布式低功耗免布线照度采集终端、以及本地部署有神经网络计算芯片与推理固件的边缘决策控制器；所述决策控制器接收多模态环境数据与照度、眩光度矩阵，提取眩光反射特征，通过推理固件进行自学习推理，动态调节黑板板面偏角、遮光板深度、补光灯照度及多媒体显示模块表面的液晶附加电控偏光膜的物理偏光角度，实现无眩光高清投影。本实用新型作为去年11月提交的核心在先案的完善补全专利，重点细化了机械快拆兼容性、轨道排砂自洁以及智能硬件控光方案，具备极高的防御与保护价值。

3. 🔍 背景技术与完善补全定位（在先提交背景与技术缺陷）

申请人已于去年11月份左右，针对在先基础型折叠翻转多媒体教学黑板及光环境系统，提交了“发明专利与实用新型专利的同日共同申请”。该在先案奠定了本系列产品“主体-旋转铰链接触-黑板模块折叠切换与偏光抗光”的底层核心保护防线。

然而，在在先基础型同日双申案向产业化、大尺寸屏适配落地的过程中，暴露出以下亟待“完善补全”的微观物理构造及智能控光问题。在申请人针对中国专利公开数据进行的主动查新检索中，发现了如下相关在先技术公开情况：

导轨防尘嵌套对比：

在先公开专利 CN215383921U（[一种多媒体教学黑板用防尘嵌套导轨组件](http://epub.cnipa.gov.cn/cred/CN215383921U)，公开日：2022-01-04）公开了一种防尘嵌套导轨，其采用固定底框与滑动内轨，并在端部设磁性定位扣以减缓灰尘堆积。

本案技术区别与完善：该在先专利无法解决由于大跨度延伸导致的悬臂下垂弯矩，且其滑槽在频繁滑动时容易积砂卡死。本实用新型在滑轨末端补充了“偏心楔形自锁防下垂凸台与锁紧卡口”，在滑动就位时切入卡槽死死卡紧，消除机械配合公差；并设计了“上盖倒V型防护罩+中部尼龙毛刷+下部每隔200mm圆孔垂直排砂防气阻”的重载自洁除尘结构，轨道拉伸寿命延长10倍以上。

主动控光避光对比：

在先公开专利 CN113298319A（[一种基于环境照度与眩光自适应调整的智能教学黑板系统](http://epub.cnipa.gov.cn/cred/CN113298319A)，公开日：2021-08-24）公开了采集实时照度并计算出眩光反射角，通过控制器驱动电动推杆拉动黑板做一维偏航避光的方案。

在先公开专利 CN212391823U（[一种多媒体教室用光强补偿与主动避光黑板系统](http://epub.cnipa.gov.cn/cred/CN212391823U)，公开日：2021-01-22）公开了通过摄像头采集眯眼率，中控调节屏幕亮度并联动拉合窗帘的方案。

本案技术区别与完善：上述在先专利均属于单维度机械偏航避光或拉窗帘，无法解决多角度交叉眩光反射。本实用新型补全了“偏航旋转 + 纵向俯仰 -15° ~ +15°（蜗轮蜗杆减速自锁马达） + 水平侧向滑移 1.0 米”的三维复合运动副，使黑板能够实现三维空间微调反射角度，将反射眩光物理折射到无人走廊；并配以贴装于屏幕表面的外置液晶偏光膜做 0° ~ 90° 电控齿轮无级微调，构成全方位避光防线。

双面书写挂载对比：

在先公开专利 CN207439121U（[一种正反双面磁吸式教学黑板](http://epub.cnipa.gov.cn/cred/CN207439121U)，公开日：2018-06-01）公开了一种四周设有铁质吸附边框的正反双面磁吸黑板，可取下翻面使用。

本案技术区别与完善：该在先专利属于支架上整体大面积贴合，不具备模块化升级与材质混合适配能力。本实用新型设计了“正面与反面完全对称布置相同规格标准化磁吸座/卡扣”的黑板主体，其双面可为同质介质（双绿板延长一倍寿命）或异质介质（一面绿板粉笔，另一面珐琅白板水性笔/投影板），用户可就地进行 5 秒无工具翻面卡挂，或随时更换其他定制规格板体，极大地丰富了多媒体交互并锁死售后升级路径。

5. 🛠️ 具体实施方式

5.1 机械骨架与快拆升级实施

本实施例的装配关系与去年11月提交的在先案保持向下兼容：

根部承重轴（Hinge_Left/Right）打在承重墙面上，其上端加工有标准化插接母座。

标配一案形式运行：当挂载在先基础型固定宽度翻转架时，框架仅能在铰链轴驱动下做 30° 旋转，通过翻转板快拆磁吸黑板模块。

就地升级二案形式运行：无需拆卸铰链轴，拔出销钉即可将在先基础型固定翻转架拆下，将二代双横梁固定外框（Fixed_Frame）通过俯仰摆动轴组件插进该母座中锁紧。所述俯仰摆动轴组件包括贯穿插接母座的水平铰接销轴与俯仰驱动马达，所述水平铰接销轴的轴线呈水平方向延伸，所述俯仰驱动马达固定在插接母座外侧，其输出端通过蜗轮蜗杆减速箱与所述水平铰接销轴传动连接，利用蜗轮蜗杆的物理自锁特性，以在断电或锁死状态下防止重载的大跨度黑板悬臂因重力力矩下坠倾覆。当边缘决策控制器输出俯仰驱动电信号时，所述俯仰驱动马达驱动整个双横梁固定外框（包括内部嵌套的延伸轨和黑板主体）绕水平铰接销轴在垂直面内进行 -15° ~ +15° 的俯仰倾斜摆动，构成纵向避光的第二维度运动副。同时，利用嵌套在滑轨内部的不锈钢延伸轨（Extension_Rail）水平侧向滑移，可将黑板主体朝外侧推移 1.0 米，扫除大液晶屏两侧的物理遮挡，实现可视盲区归零。为了消除滑轨拉出至最大行程时悬臂梁的重力弯矩下垂，在嵌套滑动延伸轨的内滑入端部外侧固定设有偏心楔形自锁防下垂凸台，而在双横梁固定外框的 C 型滑槽水平滑移终点内壁处对应开设有一锁紧卡口；当嵌套滑动延伸轨水平侧向滑动拉伸至终点限位处，所述自锁防下垂凸台在摩擦导向作用下切入并偏心楔紧在所述锁紧卡口中，通过偏心斜面过盈卡紧物理抵消悬臂下垂，确保黑板面与大液晶屏表面保持完美的平行与高度对齐。

黑板主体双面可拆卸翻面选配结构：本实施例中，黑板主体（DoubleBoard）采用多介质选配的可拆卸翻面结构。黑板主体的正面与反面可以选配为相同书写介质（例如正反面均为绿色粉笔书写面以延长使用寿命），亦可选配为不同书写介质（例如正面为绿色粉笔书写面，反面为白色搪瓷无尘马克笔或可投影防眩白板面，以供教师灵活选择书写工具）。黑板主体的正面和反面四周边缘，均完全对称地设有一圈规格完全相同的标准化高强磁吸扣，用于贴合吸附挂载在延伸轨上。当教师需要切换教学书写工具，或因正面磨损需要维护时，校工无需任何外部工具，可直接将黑板主体取下，水平翻转 180° 后以反面贴合挂回；同时，用户亦可根据学校定制需求，选配另一块正反均为白板或正反均为绿板的备用黑板主体进行就地拔插替换，极大地提升了板面书写的自定义度与适配度。

5.2 导轨自洁防尘与排灰导流路径实施

为了防止细微的粉笔灰积聚卡死：

阳极氧化铝合金（6063-T5）上横梁的 C 型滑槽顶部扣装有倒 V 型的弹性 EPDM 橡胶密封防尘罩，用以阻挡 95% 以上直落的粉笔灰；

上横梁与下横梁 C 型滑槽的金属槽底，沿水平抽拉方向以 200mm 的等间距开设有一排贯穿垂直排灰导流孔。在延伸轨的滑动受摩擦表面上紧贴有一排高密度的微细尼龙毛刷；此外，所述嵌套滑动延伸轨包括上延伸滑轨、下延伸滑轨及端部拉杆，所述上延伸滑轨与下延伸滑轨分别滑动嵌套于对应的 C 型凹槽滑道中，其横向外展端部之间通过竖直方向的所述端部拉杆做刚性锁定连接（例如通过端部连接法兰和固定螺栓锁紧，或者焊接成一体式 C 型滑框组件）；由此利用所述端部拉杆将上延伸滑轨和下延伸滑轨的水平位移进行刚性运动耦合，以增强延伸轨在悬臂拉出至最大行程状态下的整体结构刚度，并保证上下滑轨在受力侧滑抽拉时的机械同步，杜绝滑轨在悬臂重载下发生扭转形变。

排灰路径：当延伸内轨沿 C 型凹槽水平向外抽拉或退回时，尼龙毛刷条会像雨刮器一样沿槽底摩擦运动，将侵入的微量粉笔灰朝两侧推扫，灰尘在清扫力作用下落入排灰导流孔中，经重力垂直向下排出轨道腔体外，落入外框下横梁底部外挂的集灰槽中。排灰导流孔在排尘的同时实现了内外腔体压平衡，消除了毛刷密闭腔滑动时的气阻干涉。

5.3 偏振片调节马达的物理实现细节

本实施例中，对于液晶多媒体显示屏，偏振片的物理微调组件构造如下：

外置电控液晶偏光膜结构：本装置的偏振片并非指液晶面板内部自带的偏光板，而是额外贴合于液晶大屏最外层防爆玻璃外屏表面的外置附加电控液晶偏光膜层，避免对屏体内部自发光偏振轴造成干涉。

驱动安装与耦合方式：多媒体显示模块的铝合金内边框死角处固定安装有一台超微型直流精密伺服电机；该电机的输出端齿轮与贴合于偏振片外缘的一圈柔性超薄精密外齿圈相齿合耦合。

微调旋转范围：边缘决策控制器输出微调脉冲给伺服电机，电机通过外齿圈带动外置偏振层在 0° ~ 90° 范围内进行连续无级旋转，使其偏振轴线能够按决策控制器电信号指令动态对齐并过滤偏振反射光。

遮光板与电机的物理实现：主体框架顶部水平设有卷轴式遮光板，所述遮光板电机的输出端与所述遮光板的卷轴传动连接，遮光板电机固定安装于所述主体框架的顶罩内部；边缘决策控制器与所述遮光板电机电信号连接，通过驱动遮光板电机正反转以带动卷轴收卷或释放遮光板，实现遮光深度的无级可调。上述偏光膜和遮光板调节仅在液晶自发光屏上配置；当多媒体显示模块为投影白板或布幕时，控制模块通过直接控制铰链旋转及教室补光灯亮度来降低光反射。

5.4 AI多模态主动控光系统闭环、供电与芯片细节

本实施例中，主动控光的核心链路与硬件细节如下：

边缘控制器与大模型运行规范（规避纯算法不适格风险）：

边缘决策控制器采用内置有神经网络加速器（NPU，如搭载嵌入式 NPU 推理引擎的主控板）的本地微处理器硬件芯片。

控制器固件内烧录有经 8bit/4bit 整型量化（INT8/INT4）压缩的轻量化大语言模型（LLM）权重矩阵。该本地模型利用“窗边反射强眩光、多角度学生眯眼程度、各座位实地采集历史光感对比度”等实地照度数据集微调而成，监督信号为“在不同照度及眩光对比度组合下，学生视觉瞳孔收缩度与舒适度的主观量化标签值”。

模型的单次前向推理延迟控制在 50 毫秒以内，规避了由于网络延迟导致的光环境控制滞后。详细的强化学习闭环损失函数及动态时序算法逻辑，保留在后续发明专利申请中，本实用新型重点保护上述边缘控制器硬件与外围光电接口的系统层拓扑。

分布式免布线照度采集终端的供电与通信：

免线供电：教室内每一个课桌椅边角卡装的照度终端，其上表面集成有非晶硅室内太阳能集能板。在教室内日光灯开启状态下，集能板产生微电流并储存在终端内部的超微型蓄电超级电容内，配合免维护的长寿命纽扣锂电池做备用供电，彻底免除强电或弱电施工物理布线。

Mesh无线自组网：照度终端内置超低功耗的 2.4GHz BLE Mesh（低功耗蓝牙网格网络）通信芯片。

数据上传频率：当教室内光线稳定平缓时，终端仅以 1次/分钟 的极低频心跳发送本地平均照度数据以节省电能；当窗边强光直射导致局部照度突变超过 5% 时，终端瞬间被外部中断唤醒，主动向边缘决策控制器瞬时上传突变参量，实现极速动态响应。
