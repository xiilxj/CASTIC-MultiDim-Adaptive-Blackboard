## 一、 修正说明与设计变更概要

针对初版图纸反馈，本次 v2.1 进行了两项核心技术重构：
1. **中文字体问号乱码彻底修正**：
   - 根本原因：AutoCAD 原生 Standard 文字样式默认绑定英文 `txt.shx` 单线字体，在直接解析中文 Unicode 时字形库缺失导致问号乱码。
   - 解决方案：在 AutoCAD COM 核心驱动中动态注入 `STYLE_GB_CN` 文本样式，强制关联 Windows 原生 `SimHei.ttf`（黑体）TrueType 矢量字库，并将系统标注变量 `DIMTXSTY` 全局指向该样式。所有图名、引线说明、标注文字均实现 100% 纯正工程中文显示。
2. **重磅新增【完全覆盖状态】工况图（用户重点指示）**：
   - 完整构建推拉黑板的两大核心工作状态对比：
     - **工况一【开启状态·多媒体教学模式】**：两扇活动推拉板向左右两端完全滑开停靠，中间 86 寸液晶一体机完全裸露；
     - **工况二【完全覆盖状态·全黑板书写与屏保模式】**：两扇活动推拉板沿滑轨向中心滑移闭合，在中央严密锁合，将中间 86 寸液晶一体机 100% 完全遮蔽覆盖保护，呈现 4000mm 连贯书写大黑板。
   - 结合**工程隐蔽虚线透视（DASHED）**，直观展现被完全遮挡后的大屏空间位置与保护状态。
3. **增加双导轨横向俯视截面运动原理图**：
   - 清晰剖切后层安装平面与前层滑轨悬挂平面的层级关系，标明 15mm 安全防擦碰间隙与 1000mm 滑移行程。
4. **坚持纯工程线框制图**：
   - 100% 零 Hatch 填充色块，符合专业级机械工程蓝图出图标准。

### 2. 工况一：开启状态（多媒体交互教学模式）
- **适用场景**: 教师使用 86 寸触控一体机播放 PPT、运行教学软件、电子板书。
- **构件分布**:
  - **左活动黑板**: 滑移至最左端（X: 0 ~ 1000mm），停靠在左固定黑板正前方重叠；
  - **中置 86 寸一体机**: 完全外露（X: 1000 ~ 3000mm），外框 2000×1200mm，有效显示区 1900×1070mm（16:9 标准比例），下置控制槽宽 90mm；
  - **右活动黑板**: 滑移至最右端（X: 3000 ~ 4000mm），停靠在右固定黑板正前方重叠；
  - **拉手位置**: 左板拉手位于 X: 920mm，右板拉手位于 X: 3080mm（距各板外侧边框 80mm，拉手孔径 Ø28mm）；
  - **指示箭头**: 左右板面标注 `[向左滑移开启]` 与 `[向右滑移开启]`。

---

### 3. 工况二：完全覆盖状态（全黑板书写与屏保模式 - 核心新增！）
- **适用场景**: 下课闭合保护大屏、纯粉笔大篇幅板书授课、防尘防外力误撞击。
- **构件分布**:
  - **左固定黑板面 (外露)**: X: 0 ~ 1000mm，因左活动板移至中央而露出，提供 1.2 ㎡ 书写面；
  - **中央双扇闭合活动板 (完全覆盖区)**: X: 1000 ~ 3000mm（总宽 2000mm），**将后层 86 寸液晶一体机 100% 完全遮蔽遮挡**！
    - 左活动黑板闭合于 X: 1000 ~ 2000mm；
    - 右活动黑板闭合于 X: 2000 ~ 3000mm；
    - 后层被保护的 86 寸大屏采用工程隐蔽虚线（DASHED）透视展现；
    - **中央对接中缝 (X: 2000mm)**: 留有 4mm 缓冲对缝，内置防夹手磁吸硅胶密封毛条；
    - **中央自锁机构**: 位于中心高 600mm 处，集成防撞弹簧碰珠与机械钥匙锁芯；
    - **拉手新位置**: 随板移至中央（左拉手 X: 1920mm，右拉手 X: 2080mm），中心对称间距 160mm；
  - **右固定黑板面 (外露)**: X: 3000 ~ 4000mm，因右活动板移至中央而露出，提供 1.2 ㎡ 书写面；
  - **总书写效益**: 整机形成 4000×1200mm 无障碍大通幅连续黑板书写面，可用书写面积达到整整 4.8 ㎡！
