## 1. 第三代核心创新理念与升维架构 (Generation 3 Paradigm Shift)

第三代在第二代“三维滑轨侧滑平移推拉、自洁排灰导轨、垂直俯仰避光、AI多模态主动控光”的基础上，通过**扇叶分层与内侧铰链拓扑重构**，实现了机构自由度与教学场景的终极闭环：

1. **左右黑板模块一分为二（双层附加叠合板）**:
   - 改变二代单块 22mm 结构，采用两块超薄高刚度板面（外层主板 12mm + 内层附加板 12mm，高强度阻燃蜂窝铝夹芯 + 0.4mm 微晶搪瓷钢板）；
   - 平时两块板附加紧密叠合，叠合总厚度仅 26mm（含 2mm 隐藏式减震防撞静音垫），与单层板外包络完全一致，不额外占用教室前台纵深。
2. **黑板靠近大屏内侧竖直边缘设立铰链与一体化承重母座**:
   - 核心铰链机构（承重主铰链、标准化快拆母座、俯仰摆动电机箱、多维内缘铺开铰链）**严格设于黑板靠近中心 86 寸大屏的内侧边缘 (x = ±1000)**，坚固铰接于主体框架边框立柱；
   - 消除外侧布置导致的悬臂受力力臂过长与图面尺寸干涉问题；
   - 赋予黑板内层板向内旋转 180°“铺开封屏”的全新自由度。
3. **三大工况终极统一**:
   - **工况一【初始闭合·市面主流全覆盖封屏形态】**: 内缘铰链向中心铺开 180°，左右内层板相向合拢锁定，完全遮蔽保护 2000mm 大屏，呈现 4000mm 传统推拉黑板主流纯板书形态；
   - **工况二【常态多媒体·大屏露显叠合形态】**: 内缘铰链折回 180°，双板紧密叠合于大屏两侧，86寸大屏全景呈现；
   - **工况三【大视野与避光·平移侧滑展开形态】**: 叠合板沿双横梁自洁滑轨向外直线侧滑 1000mm（总宽达 6000mm），依靠高刚性伸缩套杆承托，并执行 -15°~+15° 纵向俯仰与伺服偏光防眩。

## 3. 多维铰链系统与机构拓扑 (Hinge Kinematics)

1. **多维内缘铺开铰链 (Inner Spreading Hinge)**:
   - **安装位置**: 严格设于黑板靠近中心大屏的内侧竖直边缘 (x = ±1000)；
   - **回转范围**: $0^\circ \sim 180^\circ$；
   - **构造型式**: 隐藏式上下双枢轴重载铰链（304 不锈钢 $\Phi 12\text{mm}$ 轴心，内嵌铜基自润滑含油轴承）；
   - **对撞锁紧**: 左右内层板在屏幕中央相向合拢时，端部设有碰珠式磁吸机械自锁扣，受力平整不晃动。
2. **承重转轴主铰链与标准化快拆母座 (Quick-Release Socket)**:
   - **安装位置**: 设于主体框架靠近大屏内侧垂直边框 (x = ±1000)；
   - **升级兼容**: 带有快拆销钉孔，拔出插销即可实现一代、二代、三代机构原位互换升级。
3. **俯仰摆动轴组件 (Pitch Swing Axis)**:
   - 设于内侧主转轴后方，水平铰接销轴 + 蜗轮蜗杆自锁减速电机，驱动黑板模块做 $-15^\circ \sim +15^\circ$ 纵向俯仰避光。

## 4. 自洁排灰导轨与工况三双侧伸缩杆系统 (Self-Cleaning & Telescopic Rods)

1. **双横梁固定外框与外露自洁滑槽**:
   - 侧滑拉出 1.0 米后，在大屏与黑板之间露出 1000mm 间隙（左侧 -2000~-1000，右侧 1000~2000）；
   - 暴露上、下 6063-T5 铝合金 C 型滑槽，槽底每隔 200mm 等间距开设 $\Phi 12\text{mm}$ 垂直排灰圆孔（每侧各 5 个）；
   - 倒 V 型 EPDM 橡胶罩配合高密度尼龙雨刮毛刷，在侧滑往复运动中自动推扫粉笔积灰并消除气阻。
2. **高刚性横向伸缩内套杆（两边伸缩的杆）**:
   - **构造型式**: 每侧上下导轨内部各配置一根 $\Phi 28 \times 2.5\text{mm}$ SUS304 高强度不锈钢伸缩内套杆；
   - **安装方式**: 套杆根部紧锁于大屏内侧边框基座，外端深锁入外滑黑板主体框架；
   - **导向与限位**: 设 120mm 长自润滑铜套限位套筒，1.0 米滑移极限处刚性抵消自重悬臂弯矩。
3. **刚性垂直端部拉杆 (End Tie Rods)**:
   - 位于最外端（左端 x = -3000，右端 x = +3000）；
   - 刚性垂直机械锁定上下滑轨外展端头，形成完全封闭的矩形力学框架，彻底杜绝悬臂扭转形变。
4. **$3.5^\circ$ 偏心楔形自锁防下垂凸台**:
   - 设于滑移行程终点 (x = ±2000)，侧滑拉出到位时自动楔入卡口，消除间隙。
